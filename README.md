# The Progressive Conservatives

A static founding political vision by Charles Leone. This is not an FEC-registered party or a claim of ballot registration.

## Files and hosting

`index.html` and `styles.css` are the complete site. There is no build step, JavaScript, analytics, or external dependency. Open `index.html` directly, or serve this directory with any static web server.

For GitHub Pages, place these files at the root of the intended repository and configure Pages to serve that root. `.nojekyll` keeps the files unprocessed. All page navigation uses internal anchors. Nothing has been published by this file build.

## Source

The supplied PROGRESSIVE-CONSERVATIVES.md platform is the source of the page text. The platform is presented in Charles Leone’s own political voice.
